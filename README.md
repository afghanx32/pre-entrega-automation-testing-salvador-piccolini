# Pre-Entrega Automation Testing — SauceDemo

Automatización de flujos básicos en `saucedemo.com` utilizando Python, Selenium WebDriver y Pytest.

## 🚀 Tecnologías
- Python, Selenium, Pytest, Webdriver-Manager, Pytest-HTML.

## ⚙️ Instalación y Ejecución
1. Crear entorno virtual: `python -m venv venv`
2. Activar entorno: `venv\Scripts\activate`
3. Instalar dependencias: `pip-install -r requirements.txt` (o `pip install -r requirements.txt`)
4. Ejecutar tests y generar reporte: `pytest -v --html=reports/reporte.html --self-contained-html`
